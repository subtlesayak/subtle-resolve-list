Resolve-Codec-Converter

Linux batch transcoding GUI for H.264/H.265, DNxHR and ProRes, including PCM audio conversion and a video-passthrough audio mode. Useful for preparing footage for Resolve Free on Linux. The x64 AppImage bundles PyQt5/Qt5; FFmpeg must be installed separately. Release tag is a build label, not a numeric version.
